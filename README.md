# POISE: Smartphone-Based Markerless 3D Motion Capture
Posture Observation and Insight via Smartphone Evaluation (POISE)  
An open-source, field-ready pipeline for ergonomic risk assessment using smartphone videos and Python-based tools.

Features
- Markerless 3D motion capture using multi-camera setup
- GUI-based tools for calibration and pose analysis (KinemaTrack, PoseTrack)
- < 15 min setup, smartphone-only, accurate (RMSE < 11°)
- Scalable & portable for workplace and field studies
